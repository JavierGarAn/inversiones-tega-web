Paso a Paso para Conectar tu Dominio Oficial

Para vincular tu dominio (ejemplo: inversionestega.pe o inversionestega.com), solo debes configurar los siguientes registros DNS en el panel donde compraste tu dominio (ej. Nic.pe, GoDaddy, Hostinger, Namecheap o Cloudflare):

Tipo Nombre / Host Valor / Destino Finalidad
A @ (o vacío) 76.76.21.21 Apunta tu dominio principal hacia el servidor global (Vercel CDN)
CNAME www cname.vercel-dns.com Permite que los usuarios ingresen escribiendo www.tudominio.pe
